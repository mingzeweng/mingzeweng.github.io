# Mingze Weng

Personal research website: [mingzeweng.github.io](https://mingzeweng.github.io/).

The site is built with plain HTML, CSS, and JavaScript and published with GitHub Pages. No build step is required.

- `index.html` contains the profile, publications, news, and academic background.
- `styles.css` contains the responsive layout and visual styles.
- `preview.js` plays research previews on hover, with touch and keyboard controls and reduced-motion support.
- `assets/` contains the portrait, institution logos, and research media.

To preview locally, run `python3 -m http.server 8766` and open `http://localhost:8766/`.

Research previews are excerpts from the corresponding project demonstrations and paper figures. The relevant papers and project pages are linked beside each preview.

The footer shows page views using [Busuanzi](https://busuanzi.ibruce.info/). `views.js` counts only visits to `https://mingzeweng.github.io/`; local previews and other hosts do not submit views. The counter uses this site's own total, with no historical offsets. If the service is unavailable, the footer displays `— views` until a valid response arrives.
