# Mingze Weng

Personal research website: [mingzeweng.github.io](https://mingzeweng.github.io/).

The site uses plain HTML, CSS, and JavaScript. No build step is required.

- `index.html` contains the profile, news, publications, preprints, education, experience, and academic service.
- `styles.css` contains the page layout and styles.
- `preview.js` plays research previews on hover, with touch and keyboard controls and reduced-motion support.
- `assets/` contains the profile photo, favicon, institution logos, and research media.

To preview locally, run `python3 -m http.server 8766` and open `http://localhost:8766/`.

Research previews are excerpts from the corresponding project demonstrations and paper figures. The relevant papers and project pages are linked beside each preview.

Covers use complete original published figures, preserving all panels, labels,
native colors and aspect ratios on white. Hy-Nomas uses the full Figure 1. Hunyuan-Game uses
the complete original Figure 19 character-consistency pipeline.


Previews remain silent 5–8 second excerpts. Hover plays a clip; leaving restores
the cover. Touch and keyboard users can toggle playback. Reduced-motion
preferences disable automatic hover playback. Static-paper transitions are
editorial reveals, not synthesized results.
